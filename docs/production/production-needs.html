WonderHome — What I need from you for production

Owner checklist · 25 September 2026 · Tick each item when done

1. Do first

#TaskHow
1Rotate the Gemini keyCreate a new key in Google AI Studio, update WONDERHOME_AI_KEY in Vercel, then revoke the old key. The old key was pasted into chat earlier.
2Redeploy production onceCRON_SECRET is now set in Vercel. A redeploy makes sure the nightly jobs (reminders, retention, payment reconciliation, webhooks) run with it.
3Supabase Auth settings
  • Set the Site URL and redirect URLs to your domain.
  • Add custom SMTP. The built-in email sender is rate-limited.

2. To take payments

#TaskHow
4Razorpay (India)
  • Set RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET and RAZORPAY_WEBHOOK_SECRET.
  • Set WONDERHOME_BILLING_PROVIDERS=razorpay.
  • Point the webhook at /api/v1/billing/webhook/razorpay.
  • Create the Pro and Max plans in Razorpay and send me their plan IDs to map.
5Stripe (other countries)The same steps, with STRIPE_SECRET_KEY and STRIPE_WEBHOOK_SECRET.
6Decide when to go liveTell me when, and I mark the plans as paid. Prices are already set: ₹299 / ₹599 a month.

3. Optional channels

Each stays off until you set it up. Nothing breaks if you skip one.

#TaskHow
7Voice (story 04-017)
  • Create the Alexa skill and set the ALEXA_* variables.
  • Test Gemini Live on a real device.
8WhatsAppCreate a Meta business app, then set:
  • WHATSAPP_ACCESS_TOKEN, WHATSAPP_PHONE_NUMBER_ID, WHATSAPP_TEMPLATE_NAME
  • WHATSAPP_APP_SECRET, WHATSAPP_VERIFY_TOKEN, WHATSAPP_BUSINESS_NUMBER
9Email forwarding into HomeSendSet up a Resend account with a verified receiving domain, then set RESEND_API_KEY and RESEND_WEBHOOK_SECRET.
10Switches, each only if you want it
  • WONDERHOME_WEATHER_PROVIDER=open-meteo: weather
  • WONDERHOME_MALWARE_SCAN_ENDPOINT: virus scanning of uploads
  • Google sign-in: enable Google in Supabase, then set NEXT_PUBLIC_GOOGLE_AUTH_ENABLED
  • WONDERHOME_DEVELOPER_API=on: only when you have a partner to give a key to
